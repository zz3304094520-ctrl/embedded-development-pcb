# 慧田智测管理后台 PRD

## 目标

新增独立 Web 管理后台，端口 `9528`，连接现有 FastAPI `8000` 端口。首版覆盖运行总览、农场/地块/设备管理、传感器数据、告警规则与告警处置、控制命令和诊断记录，不包含账号权限和真实 AI 模型训练。

## 用户故事

- 管理者打开首页即可看到 API、数据库、设备、活动告警和最新数据状态。
- 运维人员可以新增、编辑和删除农场、地块、HTTP 设备，并看懂删除失败原因。
- 技术员可以筛选传感器数据、查看趋势和管理阈值告警规则。
- 值守人员可以确认/解决告警，创建水泵或补光灯控制命令。
- 现场人员可以在 H5 的设备区看到水泵和作物补光灯，查看 Jetson 回报的真实继电器状态，并执行有限时长的开启或立即关闭。
- 项目负责人可以查看诊断记录，并跳转到 H5 现场监测页面。

## 页面范围

1. 总览：运行状态、核心数量、活动告警、最近读数、指标趋势。
2. 农场与地块：增改删、归属和面积信息。
3. 设备管理：增改删、在线状态、通信方式，默认仅允许创建 HTTP 设备。
4. 传感器数据：按地块/设备筛选，趋势图与明细表。
5. 告警中心：规则增改删、告警筛选、确认和解决。
6. 控制命令：创建命令、查看状态和参数。
7. 诊断记录：按地块筛选并查看已有诊断结果。

## 验收标准

- `npm run build` 和 TypeScript 检查通过。
- 后端原有 pytest `10/10` 通过。
- 管理后台在 `http://172.20.10.2:9528` 可访问并通过 Vite proxy 调用 API。
- 所有页面具有 loading、empty、success、error 状态。
- CRUD 成功后列表自动刷新；删除具有二次确认；后端 `409/422` 原因可读。
- HTTP-only 配置下健康接口显示 MQTT disabled，页面不把它当作故障。
- 桌面宽度 `1440px` 与平板宽度 `768px` 无关键内容溢出。
- 初始化后必须存在 `pump-001`（水泵）和 `grow-light-001`（作物补光灯），控制命令不能再发送给气象仪或土壤传感器。
- H5 只展示与设备类型匹配的命令；点击后先显示待执行，只有 Jetson HTTP 回报后才显示继电器 `ON/OFF`。
- Jetson 从 `172.20.10.2:8000` 通过 HTTP 获取命令并回传状态，全链路不使用 MQTT。
- CH1/CH2 必须完成“启动强制关闭、短脉冲开启、到时关闭、异常关闭”验证后才算跑通。

## 风险与约束

- 当前后端没有 JWT/RBAC，管理后台仅适合本地演示或可信局域网。
- SQLite 适合 MVP，不适合高并发设备写入。
- 后端 telemetry 未提供聚合时间序列接口，首版趋势图使用最近数据绘制。
- 诊断结果是演示逻辑，不宣称真实病害识别准确率。

- 页面主要交互具有 loading、empty、success、error、focus 和 disabled 状态。
- `npm run typecheck`、`npm run build` 通过；真实浏览器 Console 无新增错误；视觉 QA 文档最终状态为 passed。

## Jetson 双路继电器接入

- Jetson Orin Nano 通过 HTTP 轮询 FastAPI 控制命令，不使用 MQTT。
- USB 双路继电器稳定设备路径使用 `/dev/serial/by-id/...7E7A69E21138-if00`，不依赖易变化的 `/dev/ttyACM0`。
- 通道固定映射：CH1 为水泵，CH2 为作物补光灯；`pump_*` 只允许操作 CH1，`light_*` 只允许操作 CH2。
- 首次部署必须保持 `dry-run=true`。只有在负载断电、协议确认、通道短脉冲验证通过后才能关闭 dry-run。
- `pump_on` 与 `light_on` 必须提供 `1..300` 秒的 `duration_seconds`，到时强制关闭，避免水泵空转或补光灯长时间误开启。
- “继电器 ON/OFF”表示 Jetson 已完成串口写入或查询，不代表已经检测到真实水流或光照；物理闭环仍需流量计或光照传感器。

## D435i 实时病害监测

### 目标

- H5“现场设备”中显示 `Jetson D435i 智能巡检节点`，并在设备区下方直接播放 Jetson 提供的 MJPEG 实时画面。
- Jetson 在本地使用 YOLO `.pt` 模型完成推理；视频帧不经过 Windows FastAPI，FastAPI 只接收设备注册/心跳和结构化病害识别结果。
- 病害卡片展示类别、中文名称、严重程度、健康状况、目标距离、检测时间和处置建议。
- 右侧结果区以“识别种类 / 小番茄作物概况”为固定信息层级，不再把未配置类别放大显示为“番茄异常”。

### 验收标准

- 兼容现有 Jetson 服务的 `POST /camera/edge/register` 与 `POST /camera/edge/detections` 请求格式。
- `GET /api/v1/detections` 可按 `plot_id`、`device_id` 查询并限制返回数量。
- 相机注册后设备显示在线并保存动态 `stream_url`；前端不硬编码 Jetson IP。
- D435i 拔出后，Jetson 服务不中断并持续探测相机；后端收到离线心跳后，H5 无需刷新即可显示“设备离线”。
- D435i 重新插入后，Jetson 自动恢复采集和 YOLO；后端收到在线心跳后，H5 无需刷新即可重新挂载同一 MJPEG 地址。
- MJPEG 使用浏览器 `<img>` 直连 Jetson，FastAPI 不代理、不落库视频帧。
- 视频不可用时页面显示明确的离线/重连状态，其他设备与控制功能不受影响。
- Jetson 对每个采集帧执行一次 YOLO；模型仍用真实阈值判断类别和框。前端不展示模型置信度，改为每 5 秒在 `60%..75%` 范围随机刷新的“健康状况”演示值。
- 后端测试、前端 `typecheck` 与 `build` 全部通过。

### 风险与约束

- 热插拔不是零延迟：当前相机重试周期为 5 秒、状态心跳周期为 10 秒，最坏约 15 秒完成前端状态切换。
- H5 与 Jetson 必须处于可互访局域网；若未来 H5 改为 HTTPS，HTTP MJPEG 会被浏览器当作 mixed content 阻止。
- 自动识别结果属于辅助判断，不能替代农技人员确认。
- 动态健康状况仅满足演示口径，不是由图像、传感器或模型计算得出，不能用于农艺决策。

## 真实土壤与气象传感器接入（2026-07-23）

### 目标

- Jetson Orin Nano 从两路 USB-RS485 设备采集真实 Modbus RTU 数据，并通过既有 FastAPI `172.20.10.2:8000` 上报；不新增对外网络端口。
- H5 在原有“环境监测”区域中分别展示气象站与土壤传感器，沿用现有卡片、颜色和响应式布局，不引入突兀的新页面。
- 传感器拔出、无响应或协议尚未确认时必须显示离线/暂无数据；禁止使用随机数、固定演示值或历史演示值冒充实时数据。

### 已确认硬件基线

- Jetson 地址为 `172.20.10.4`，FastAPI 地址为 `http://172.20.10.2:8000`。
- 气象站型号标签为 `SN-3003-FSXCS-MD1`，稳定 USB 路径为 `/dev/serial/by-path/platform-3610000.usb-usb-0:2.2.2:1.0-port0`，已确认 `4800bps / 8N1 / Modbus 地址 1 / Function 03`。
- 气象站已取得 CRC 正确的真实空气温度、空气湿度、光照与雨量寄存器数据。定制寄存器 `506=300` 在厂商协议未确认前不得命名或上报。
- 土壤传感器标签确认使用 RS485、`5–24V` 供电，稳定 USB 路径为 `/dev/serial/by-path/platform-3610000.usb-usb-0:2.2.4:1.0-port0`；适配器可打开，但当前在常用串口参数与只读寄存器下没有收到 Modbus 响应。
- 两只 CH340 适配器报告相同且不唯一的 USB serial，不能依赖 `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`；当前部署按物理 USB `by-path` 路径区分。

### 验收标准

- 气象站每 5 秒采集一次，至少上报 `air_temperature`、`air_humidity`、`illumination`、`rainfall`，数值与同一时刻原始寄存器及倍率一致。
- 土壤传感器只有在取得 CRC 正确响应并确认寄存器倍率后，才上报已验证指标；未读通时 `soil-001` 保持离线且 H5 不显示数值。
- Jetson 通过 `POST /api/v1/telemetry` 批量上报一次采样；串口断开时通过设备状态接口将对应设备标记离线，另一只传感器继续工作。
- H5 只展示 `weather_station` 与 `soil_sensor` 类型的传感器，按设备分组显示在线状态、最新值和采样时间；旧值可保留，但必须明确标注其采样时间与设备离线状态。
- WebSocket 收到 `telemetry.created` 或 `device.status_changed` 后，只刷新设备与传感器数据，不重复加载相机、诊断、命令等无关资源。
- 后端 pytest、Jetson Agent 单元测试、前端 `npm run typecheck` 与 `npm run build` 全部通过，并用现场 API 验证气象真实值成功入库和显示。

### 风险与约束

- 土壤探头当前无 Modbus 响应；在检查独立供电、共地、黄线 A/绿线 B、A/B 极性及厂家地址/波特率之前，无法宣称土壤数据已接通。
- `by-path` 与物理 USB 插口绑定；更换 Hub 插口后需要同步更新配置。若后续更换为具有唯一序列号的适配器，应迁移到稳定 `by-id` 或专用 udev 别名。
- FastAPI 当前历史库含演示读数，实时卡片必须按 `device_id + metric` 选择最新读数，不能用全历史 summary 的均值/极值表示当前现场状态。
